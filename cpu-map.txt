================================================================================
Źródło prawdy (persist): /etc/sdboot-manage.conf → LINUX_OPTIONS
  (sdboot-manage przepisuje /boot/loader/entries/*.conf z tego przy każdym update)

Isolation-relevant (live, zweryfikowane):
  irqaffinity=0,7,8,15         (GPU IRQ→0 dokłada hardware.sh runtime)
  systemd.cpu_affinity=0,7,8,15
  processor.max_cstate=1       (eliminuje idle frame drop, 0.1% low)
Reszta: amdgpu.cwsr_enable=0 / gpu_recovery=1 / ppfeaturemask=0xffffffff, amd_pstate=active,
        mitigations=off, split_lock_detect=off, transparent_hugepage=madvise,
        pci=pcie_bus_perf, nvme_core.default_ps_max_latency_us=0, usbhid.mousepoll=4, zswap.enabled=0

   ale NIE MA go w LINUX_OPTIONS → zniknie po następnym sdboot-manage rewrite. Patrz WATCH.

hardware.sh (hardware.service, boot oneshot) — JEDNO ŹRÓDŁO sprzętowego tuningu
================================================================================
Zastąpił dawne udev rules (60-nvme / 61-gpu — psuły się exit 1 przez systemd-run).
  1. NVMe queue: scheduler=kyber, nr_requests=512, nomerges=0, iostats=0,
                 read_ahead_kb=128, rq_affinity=1, wbt_lat_usec=0
                 (kyber + wbt0 = storm killer; wcześniej none/rq2/nomerges2 klobrowało writes)
  2. NVMe IRQ threads: FIFO 50 → SCHED_OTHER (cache locality zostaje, nie wywłaszcza RT audio/PoE)
  3. amdgpu IRQ → CPU 0
  4. NVMe admin queue q0 → CPU 0,8
  NIE rusza: pp_power_profile_mode (właściciel = LACT/lactd, trzyma CUSTOM)

NVMe: pliku udev BRAK (60-nvme-performance.rules nie istnieje) — całość robi hardware.sh.

FRAME PACING — dlaczego AllowTearing=false + ICC kolor jest lepszy
================================================================================
4-warstwowy stack:
  1. GPL — Shader Pipeline Library (async)
  2. VKD3D Proton 11+ frame buffer — IMMEDIATE present mode + wbudowany pacing
  3. KWin compositor (AllowTearing=false) — dodatkowy bufor pacing
  4. FreeSync/VRR monitor (HDMI-A-1 vrrPolicy=Automatic)
KWin jako bufor = FEATURE. Bez ICC profilu koloru → inny render path, gorszy pacing.
no_staggered_submit ZBĘDNE na Proton 11+ (VKD3D 3.0.1+).

INNE
================================================================================
